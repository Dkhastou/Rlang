# Rlang

## Overview

### What is Rlang?

Rlang (Rapid Language) is a project coded in rust, created with heavy AI assistance, with the goal of allowing the rapid creation of languages and git-like versioning over many languages. The primary aim is to treat languages as disposable and allow for rapid iteration, creation, forking, sharing, and more. A language simply consists of a set of symbols, their meanings, and their relationships. 

There are many advantages to the creation of such a program. Some of the potential use-cases are listed in the `use-cases.md` file of this main directory. There is also  high potential for the information theoretic application of symbol generation that far exceeds what could be done otherwise. That is to say, the use of coloring, pictorial representations, and more can all be done rapidly and to a certain degree even be automated with the assistance of a computer. This means that there may be a possibility that constructed languages begin to have an edge over naturally evolved native languages. 

### Versioning and usage

Currently, the most up-to-date version is the directory titled `langsmithV2`. Simply navigate to `~/Rlang/langsmithV2/langsmith/target/release`, and enter the command `export PATH=$PATH:$(pwd)` To add the langsmith command to your path for the current session. You may also use previous versions.

Use the `langsmith` command to list all the available commands that can be used. 

### Displaying symbols

Displaying symbols in the terminal is one of the key intended features of the program. This can be done with chafa. As chafa is a third party tool that must be installed seperately from this project I cannot guarantee how it will work on other machines or local environments. 


## Long term vision

This is the first step in a communication software toolkit that I plan to build over time. The next steps will introduce language based internet networks with the goal of creating communities rapidly creating novel languages, sharing them with each other, and finally, communicating with them to allow for an accelerated development in linguistic evolution and human communication. I envision an internet with novel communication at the center of its purpose, empowering human users to expand the limits of participation and linguistic thinking rather than an internet like the one we have today, full of passive consumption and watching.
